# Security

Sherpa runs a local server that holds your GitHub token and hands tasks to an AI agent on your machine. A bug in either place can matter, so a report is welcome even when you are not sure it is a vulnerability.

Report it privately. Open the repository's **Security** tab and choose **Report a vulnerability**, or use [the advisory form](https://github.com/Nodge/sherpa-review/security/advisories/new) directly. Please do not open a public issue for it.

Say what you ran, on which version or commit, and what happened. You will get a reply within a week. Fixes go to `main`, because there are no maintained older versions.
