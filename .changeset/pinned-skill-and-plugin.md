The skill now runs the exact Sherpa release you installed instead of the newest one, so Sherpa changes only when you update it: run `npx skills update sherpa-review`, or update the plugin. Sherpa can also be installed in Claude Code as a plugin: `/plugin marketplace add Nodge/sherpa-review`, then `/plugin install sherpa-review@sherpa-review`. See [Updating](https://github.com/Nodge/sherpa-review#updating).
